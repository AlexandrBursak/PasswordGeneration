# Domain Context — password-generator

## Glossary

- password history — A local list of generated passwords that the person explicitly permits the application to retain. NOT a password manager or a synchronized vault; it has no account, sharing, or cross-device synchronization.
- person — Someone using the password generator in their browser. NOT an authenticated account or a privileged administrator; the MVP has neither.
